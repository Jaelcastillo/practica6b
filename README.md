# Cálculo de edad y mayoría de edad

## Descripción

Este proyecto es un programa básico desarrollado con **HTML y JavaScript**. Su función es solicitar algunos datos personales al usuario y, a partir de ellos, calcular su edad y determinar si es mayor o menor de edad.

## Funcionamiento

El programa solicita al usuario:

* Nombre.
* Apellido.
* Año de nacimiento.

Luego calcula la edad restando el año de nacimiento al año actual (2026).

Finalmente, utiliza un **operador ternario** para determinar si la persona es mayor o menor de edad y muestra toda la información mediante un `alert`.

## Archivos

**index.html:** Contiene la estructura básica de la página web y conecta el archivo JavaScript mediante la etiqueta `<script>`.

**index.js:** Contiene la lógica del programa: solicita los datos, calcula la edad, verifica la mayoría de edad y muestra el mensaje final.

## Tecnologías utilizadas

* HTML5
* JavaScript

## Conceptos aplicados

* Variables con `let`
* `prompt()`
* Operadores aritméticos
* Operador ternario
* Template literals `${}`
* `alert()`
